# Fonts

Self-hosted so the site's Content-Security-Policy can stay `default-src 'self'`.
Latin subsets as served by Google Fonts.

- **DM Sans** (`dm-sans-latin.woff2`, variable weight 400-800): body text and headings.
  © The DM Sans Project Authors. SIL Open Font License 1.1.
- **Yellowtail** (`yellowtail-latin.woff2`): the brush-script wordmark and accents.
